# MCP Catalog

On 2026-10-08 every MCP server was stopped. None start until you name one and run `zoth-mcp enable <name>`.

Registry file lists **153** servers in `/etc/zothos/mcp-servers.json`. The file currently has `enabled: true` on: `neuro-memory`. Operator policy is still: do not start the catalog.
