# Zoth AI Model Foundry & Spirit Matrix Pro

The **Zoth AI Model Foundry & Spirit Matrix Pro** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) under Studio Cockpits & Developer IDEs.

### Core Functionality
Local model manager with live GGUF, Ollama, vLLM, and LM Studio provider routing.

### Workstation Metadata
- **ID:** `models`
- **Name:** Zoth AI Model Foundry & Spirit Matrix Pro
- **Type:** `cockpit` (multi-pane developer IDE and visual operational cockpit for human-agent engineering)
- **Functional Band:** Observe
- **Static Entrypoint:** `/studio/models.html`
- **In-App Route:** `/workstations/models`

### Operational Role
Functions within the Observe band to manage and orchestrate local inference engines. It routes inference requests across local GGUF weights, Ollama instances, vLLM clusters, and LM Studio backends, presenting live model statuses and configuration controls.
