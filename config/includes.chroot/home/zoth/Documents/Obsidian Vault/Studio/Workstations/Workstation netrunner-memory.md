# Lucy Oracle Biomorphic Memory Hub

The **Lucy Oracle Biomorphic Memory Hub** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) under Hardware Enclave Daemons.

### Core Functionality
STDP biomorphic spike-timing vector memory and continuous semantic knowledge graph.

### Workstation Metadata
- **ID:** `netrunner-memory`
- **Name:** Lucy Oracle Biomorphic Memory Hub
- **Type:** `enclave_daemon` (core hardware-anchored zero-egress daemon running on local loopback)
- **Functional Band:** Studio
- **Static Entrypoint:** `/studio/netrunner-memory.html`
- **In-App Route:** `/memory`

### Operational Role
Functions within the Studio band as a biologically inspired memory subsystem. It leverages spike-timing-dependent plasticity (STDP) for associative vector recall and maintains a persistent, continuous semantic knowledge graph for local agent reasoning without external data egress.
