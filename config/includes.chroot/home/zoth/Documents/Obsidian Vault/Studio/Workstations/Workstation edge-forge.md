# Zoth Edge Forge & Micro-Kernel Sandbox

WASM module packaging, edge container compilation, and bare-metal kernel sandbox.

## Specification & Taxonomy

- **ID:** `edge-forge`
- **Name:** Zoth Edge Forge & Micro-Kernel Sandbox
- **Type:** `cockpit` (Multi-pane developer IDE and visual operational cockpit for human-agent engineering)

Registered in the Zoth Studio v2 matrix under the **Build** functional band as a studio cockpit. It provides tooling for WASM module packaging, edge container compilation, and a bare-metal kernel sandbox environment. Accessible through the static interface at `/studio/edge-forge.html` and wired into the Studio application at `/zoth-os`.
