Autonomous zero-dependency network interceptor, TLS SNI sniffer, and kinetic egress radar.

## Operational Profile

Operating within the **Security** functional band in Zoth Studio v2 as an integrated sovereign tool. Functions as an autonomous zero-dependency network interceptor, sniffing outbound TLS SNI traffic and providing a kinetic egress radar to monitor and restrict unexpected outbound communication by AI agents. Accessible directly via the static HTML cockpit, routed through the Studio tools view, or initiated as a dual-port HTTP web interface and network proxy via CLI.
