# Agent Voice Station // Full-Duplex Calling Cockpit

The **Agent Voice Station // Full-Duplex Calling Cockpit** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) as an integrated tool in the Tool Arsenal.

### Core Functionality
Sovereign full-duplex live audio calling station, 60fps Golden Orb visualizer, and 6-agent voice persona pantheon.

### Workstation Metadata
- **ID:** `agent-voice-call`
- **Name:** Agent Voice Station // Full-Duplex Calling Cockpit
- **Type:** `integrated_tool` (standalone sovereign micro-tool and CLI utility available in the Tool Arsenal)
- **Functional Band:** Studio
- **Static Entrypoint:** `/studio/voice-station.html`
- **In-App Route:** `/voice`
- **Tool Repository ID:** `agent-voice-call`
- **Pull / Launch Command:** `./bin/agent-voice-call serve --port 8114`

### Operational Role
Operates within the Studio band to deliver full-duplex voice communication with autonomous agents, featuring a 60fps Golden Orb visualizer and selection across six distinct voice personas.
