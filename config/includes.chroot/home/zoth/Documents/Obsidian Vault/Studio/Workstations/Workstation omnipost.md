Multi-platform content preview synthesizer and scheduler with live character validation.

Registered in the Zoth Studio v2 matrix under the **Spatial** functional band as an integrated sovereign tool. Provides multi-platform content preview synthesis and scheduling with real-time character limit validation. Available via the static standalone entrypoint `/studio/omnipost.html`, in-app at `/tools/omnipost-social-engine`, or pulled locally using `npx @nullaitech/zoth pull omnipost-social-engine`.
