# WebGenShowcasePage

React product showcase and landing page for **WebGen** ("Websites from Words").

- **File:** `zoth-studio-v2/src/pages/WebGenShowcasePage.jsx`
- **Route:** [[Route webgen|/webgen]]

## What It Renders

`WebGenShowcasePage` introduces the offline-first web generation engine with cyan-accented styling.

Key sections rendered:
- **Hero Section:** "Websites from Words" headline highlighting prompt-driven scaffolding, multi-framework exports, and agent workflow orchestration (Grok CLI, Hermes, OpenCode, Cline, Aider, AGY, Claude Code).
- **Daemon Status Strip:** `DaemonStatusStrip` component monitoring local engine connectivity.
- **Feature Cards:**
  - *Prompt to Website:* Instant site synthesis from natural language briefs.
  - *6 Framework Exports:* React, Vue, Svelte, Solid, Astro, or clean HTML.
  - *100% Local & Offline:* Air-gapped execution with zero telemetry.
  - *Beautiful Themes:* Built-in dark-mode design systems.
- **Target Audience ("Built For"):** Bulleted points for developers needing fast scaffolds, founders launching landing pages, and teams avoiding cloud lock-in.
- **Action CTAs:** Navigation button routing to [[Route webgen-docs|/webgen/docs]] ("Open WebGen Studio") and external GitHub repository link.
