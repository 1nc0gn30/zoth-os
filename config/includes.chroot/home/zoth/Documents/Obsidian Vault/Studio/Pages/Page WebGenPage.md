# WebGenPage

React interactive generator and documentation cockpit for **Zoth WebGen Foundry**.

- **File:** `zoth-studio-v2/src/pages/WebGenPage.jsx`
- **Route:** [[Route webgen-docs|/webgen/docs]]

## What It Renders

`WebGenPage` renders a sovereign client-side website and application generator workbench capable of compiling multi-framework frontends without external cloud dependencies.

Key sections and features rendered:
- **Template Presets:** Six pre-configured starter blueprints (SaaS Dashboard, Cyberpunk Portfolio, AI Swarm Console, Documentation Hub, Solana Web3 Mint, and Biomorphic Neuro Shop).
- **Framework Exporters:** Multi-framework code compilation supporting React 19 + Tailwind, Vue 3 Composition, Svelte 5 Runes, Solid.js 1.8, Astro 4.0, and pure zero-JS HTML5.
- **Design Token Themes:** Theme switchers for Imperial Gold, Cyberpunk Neon, Matrix Terminal, and Editorial Minimalist.
- **Guideline Skills:** Configurable generation rules covering Visual Design, SEO/AEO Graph, WCAG AAA Accessibility, 3D/Motion, Conversion Funnels, and Forms.
- **Interactive Workbench:** Real-time prompt input, compiler engine toggles (WebGPU/AST), live responsive viewport preview (desktop, tablet, mobile), and code export tools.
- **Support Components:** Integrates `DaemonStatusStrip`, `WindowCarousel`, and `SovereignFunnel`.
