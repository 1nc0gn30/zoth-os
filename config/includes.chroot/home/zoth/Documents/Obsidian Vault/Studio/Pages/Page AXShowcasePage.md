# AXShowcasePage

`AXShowcasePage` is the overview showcase page for the Agent Experience (AX) subsystem in Zoth Studio, rendered at route `[[Route ax|/ax]]`.

## Rendered Capabilities

- **Hero & Value Proposition**: Introduces machine-readable discovery interfaces enabling autonomous AI agents to locate and operate studio tools.
- **Pillar Feature Grid**: Outlines four core capabilities:
  - *Tool Discovery*: Automated agent discovery and semantic understanding of tools.
  - *Standardized Communication*: Uniform agent-to-tool messaging standards.
  - *OpenAPI Schemas*: Standard specifications eliminating custom glue code.
  - *Universal Plug-In*: Interoperability across diverse AI agent frameworks.
- **Audience Matrix**: Identifies target developer profiles (agent framework creators, LLM tool integrators, and bridge builders).
- **Navigation & Manifest CTAs**: Directs users to the in-depth documentation workbench at `[[Route ax-docs|/ax/docs]]` and links to `/.well-known/mcp.json` and `/.well-known/agent.json`.

- **Source File:** `zoth-studio-v2/src/pages/AXShowcasePage.jsx`
- **Parent / Route:** Served at `/ax` (companion documentation at `[[Route ax-docs|/ax/docs]]`)
