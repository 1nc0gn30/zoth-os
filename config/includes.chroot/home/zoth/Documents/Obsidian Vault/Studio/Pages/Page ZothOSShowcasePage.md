# ZothOSShowcasePage

React product showcase and feature comparison landing page for **Zoth OS**.

- **File:** `zoth-studio-v2/src/pages/ZothOSShowcasePage.jsx`
- **Route:** [[Route zoth-os|/zoth-os]]

## What It Renders

`ZothOSShowcasePage` showcases the flagship operating system combining Debian Trixie, KDE Plasma 6, Kali/Parrot security tooling, and local AI agent infrastructure.

Key sections and features rendered:
- **Hero Presentation:** Headline presenting Zoth OS as the sovereign alchemical intelligence and offensive security OS with cyber-gold branding.
- **Core Feature Matrix:**
  - *Dual Parity Cyber Arsenal:* 175+ pentesting and security tools providing Kali and Parrot parity.
  - *Frontier AI Agent Core:* Local Ollama on loopback, agent tool wrappers, and strict default-deny firewall configuration.
  - *Integrated Studio Cockpit:* Desktop launch of Zoth Studio v2 and its 30-tool catalog.
  - *Ghostmode Tor & Sovereign Vault:* System-wide Tor anonymization and Argon2id + AES-256 vault (`zoth-vault`).
  - *Self-Healing Daemon (`zoth-heal`):* Automated system recovery across audio, display, networking, and packages.
  - *KDE Plasma 6 Cyber-Gold UX:* Hermetic icon theme and 8 named virtual desktops (Forge, Studio, WebGen, Memory, Agents, Comms, Ops, Sanctum).
- **OS Comparison Table:** Detailed matrix benchmarking Zoth OS against Kali Linux, Parrot Security, and Ubuntu across security, agent integration, privacy, and UX dimensions.
- **Navigation & Deployment:** Direct link to documentation at [[Route zoth-os-docs|/zoth-os/docs]] and embedded `SovereignFunnel`.
