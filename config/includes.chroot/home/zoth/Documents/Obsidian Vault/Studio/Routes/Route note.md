# Studio *

Studio path `*` renders `NotFoundPage`.

- Skip intros: `?intro=0`
- Force intro: `?intro=1`
- Local: `http://127.0.0.1:3000*`
- Live: `https://zoth.nullai.tech*`

Typo-tolerant similarity on path words (/galery -> /gallery, /tool/capsule -> /tools/agent-capsule-jail).

Declared in `zoth-studio-v2/src/App.jsx`.
