# claude-design

**claude-design** is a Hermes workstation skill (not a Zoth product) that adapts the design doctrine and process of Claude Design for CLI and API agents operating outside hosted web environments.

- **Origin:** Hermes skill
- **Path:** `/home/zoth/.hermes/hermes-agent/skills/creative/claude-design/SKILL.md`

### Core Capabilities

- **Stand-alone HTML Artifacts:** Guides agents to generate complete, portable HTML/CSS/JS files for landing pages, interactive prototypes, slide decks, and component labs.
- **Surface-First Composition:** Enforces picking one of seven explicit surface archetypes (*Monitor*, *Operate*, *Compare*, *Configure*, *Decide/Learn*, *Explore*, *Command/Inspect*) before selecting tokens or colors to eliminate generic hero-plus-cards slop.
- **Anti-Slop Diagnostic:** Implements a 10-point self-audit rubric targeting AI design failure modes (unearned gradients, feature-tile grids, accent rails, unearned blurs, and centered stacks) separating diagnosis from repair.
- **Local Verification:** Mandates local file verification, browser error checks, and viewport inspection before claiming completion.

### When to Load

Load when a CLI/API agent needs to design a one-off UI artifact, prototype, or deck from scratch with high visual taste and disciplined layout. Use alongside `popular-web-designs` when matching a specific brand aesthetic, or `design-md` when authoring design tokens rather than rendered artifacts.
