# Obsidian Second Brain & Official Agent Skills

Integrates `@kepano`'s official Obsidian Agent Skills with the [[Zoth Memory]] STDP daemon (`127.0.0.1:8094`) and [[Zoth Studio]] Netrunner 3D Cortex:

1. **`obsidian-markdown`**: Native `[[wikilinks]]`, `![[embeds]]`, `> [!callouts]`, and YAML frontmatter properties.
2. **`json-canvas`**: Official JSON Canvas 1.0 (`.canvas`) spatial node & edge generator (see ![[Zoth Second Brain.canvas]]).
3. **`obsidian-bases`**: Official Obsidian Bases (`.base`) YAML relational views & formulas (see ![[Zoth Memory Stratum.base]]).
4. **`obsidian-cli`**: Live CLI & URI vault control (`obsidian://open?vault=Obsidian%20Vault`).
5. **`defuddle` & `knap`**: Clean Markdown web clipper and structured template batch renderer.
