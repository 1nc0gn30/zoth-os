# unsloth

> **Workstation Skill (Hermes)** — Origin: Hermes skill (workstation skill, not a Zoth product).

A specialized workstation skill for accelerating large language model fine-tuning with **Unsloth**, providing 2–5x faster LoRA and QLoRA training while significantly reducing VRAM consumption.

### Overview & Capabilities
- **Core Function:** Assists with Unsloth development, configuration, and debugging for memory-efficient model adaptation.
- **Model Architectures:** Optimized for popular open-weight foundation models including Llama, Mistral, Gemma, and Qwen.
- **Fine-Tuning Regimes:** Accelerated LoRA and 4-bit QLoRA fine-tuning workflows with lower GPU memory overhead.
- **Stack Dependencies:** Integrates with `unsloth`, `torch`, `transformers`, `trl`, `datasets`, and `peft`.

### When to Load
- Implementing or debugging LoRA/QLoRA fine-tuning scripts.
- Reducing training time and VRAM usage on resource-constrained GPUs.
- Inquiring about Unsloth APIs, training hyperparameters, or official architectural best practices.
- Querying structured reference documentation (`references/llms-txt.md`).
