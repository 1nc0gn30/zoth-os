Architectural, visual, and deployment blueprint for building high-converting, local-first micro-SaaS web applications and utilities.

### Core Architecture & Guidelines
- **Real In-Browser Utility:** Enforces 100% client-side execution in JavaScript/WASM for AST parsers, linters, and formatters without fake `setTimeout` placeholders or unbuilt serverless APIs.
- **Avant-Garde Dark-Glassmorphic UI:** Mandates distinctive typography (`Syne`, `Cabinet Grotesk`, `Space Grotesk`), tactile Bento grids, CSS conic border beams, aurora mesh gradients, and 60fps micro-interactions.
- **Motion Graphics Standards:** Defines Hero Anchor Shapes and production-ready showreel/launch film prompts (`prompts/motion_graphics_showreel.md`) following Claude motion design methodologies.
- **Dual Monetization Rails:** Integrates dual cash registers using Stripe Checkout payment links alongside Solana Tip Web3 Solana widgets (SOL, USDC, USDT).
- **Conversion Funnel Invariants:** Requires an above-the-fold sales banner ($0 founding pricing), a frosted-glass output blur (`filter: blur(6px)`) with paywall interceptors, and 1-click client-side license activation.
- **8-Point Pre-Deployment Guardrail:** Enforces automated headless Electron verification (`site_guardrail.js`) covering Schema.org JSON-LD graphs, robots.txt, sitemaps, Netlify redirects, accessibility, and triple-viewport responsiveness.
