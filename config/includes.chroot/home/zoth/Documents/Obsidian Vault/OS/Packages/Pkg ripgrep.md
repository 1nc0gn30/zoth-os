# ripgrep

Recursively searches directories for a regex pattern. ripgrep is a line-oriented search tool that recursively searches your current directory for a regex pattern while respecting your gitignore rules and automatically skip hidden files/directories (smart filtering) and binary files. ripgrep is similar to other popular search tools like The Silver Searcher, ack and grep.
