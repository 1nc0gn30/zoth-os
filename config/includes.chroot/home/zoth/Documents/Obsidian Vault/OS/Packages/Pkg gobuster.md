# gobuster

high-performance discovery tool for directories, DNS and cloud storage. Gobuster is a high-performance tool used to brute-force and discover: * URIs (directories and files) in web sites * DNS subdomains (with wildcard support) * Virtual Host names on target web servers * Open Amazon S3 and Google Cloud Storage (GCS) buckets * Open TFTP servers * Custom fuzzing with customizable parameters
