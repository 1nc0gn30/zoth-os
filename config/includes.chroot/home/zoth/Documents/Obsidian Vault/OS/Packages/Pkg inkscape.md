# inkscape

vector-based drawing program. Inkscape is an illustration editor which has everything needed to create professional-quality computer art. You can use it to make diagrams and illustrations, technical drawings, web graphics, clip art, icons and logos. A collection of hands-on tutorials show you how to combine lines, shapes and text of different types and styles to build up a picture.
