# kdenlive

non-linear video editor. Kdenlive is a non-linear video editing suite, which supports DV, HDV and many more formats. Its main features are: * Guides and marker for organizing timelines * Copy and paste support for clips, effects and transitions * Real time changes * FireWire and Video4Linux capture * Screen grabbing * Exporting to any by FFMPEG supported format
