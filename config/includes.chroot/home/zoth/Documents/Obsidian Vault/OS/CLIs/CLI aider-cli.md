# aider-cli

Chroot entry is a symlink → `aider`.

Image CLI `aider-cli` at `/usr/local/bin/aider-cli` (executable, 635 bytes).

Aider launcher. Prefer the Zoth venv binary so this wrapper cannot exec itself.
