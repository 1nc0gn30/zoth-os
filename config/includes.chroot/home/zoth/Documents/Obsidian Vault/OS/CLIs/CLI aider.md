# aider

`file`: Bourne-Again shell script. Script is an install wrapper in the image.

Image CLI `aider` at `/usr/local/bin/aider` (executable, 635 bytes).

**Shebang / kind:** `/usr/bin/env bash`

Aider launcher. Prefer the Zoth venv binary so this wrapper cannot exec itself.

Live host also has `/usr/local/bin/aider` after the repo↔OS sync.
