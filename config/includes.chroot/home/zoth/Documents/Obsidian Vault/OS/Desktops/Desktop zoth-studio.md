# Zoth Studio

- **Name:** `Zoth Studio`

- **Exec:** `/opt/zoth-studio/launch.sh`
- **Icon:** `zoth-studio`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Development;ArtificialIntelligence;Security;`
- **Keywords:** `studio;hub;neural;alchemical;webgl;cockpit;`
- **MIME Type:** `application/x-zoth-studio;`

## Launch Configuration & Behavior

The desktop entry registers the sovereign neural hub and tooling suite within the system application menus under Development, Artificial Intelligence, and Security. When launched, it runs `/opt/zoth-studio/launch.sh` with graphical startup notification enabled and handles the `application/x-zoth-studio` MIME type without spawning an external terminal.
