# AI Stack

## Desktop Entry Details

- **Name:** `AI Stack`
- **Comment:** `Stacked Neural Compute Chips & ML Pipeline`
- **Exec:** `xfce4-terminal -T 'AI Stack' -e 'zoth-ai-stack'`
- **Icon:** `zoth-ai-stack`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Development;ArtificialIntelligence;`
- **Keywords:** `ai;stack;neural;chips;ml;pipeline;compute;deep-learning;`
- **MimeType:** `application/x-zoth-ai-stack;`
- **Startup Notify:** `true`

## Launch Configuration & Behavior

The desktop entry registers the AI Stack application within the Development and Artificial Intelligence categories. It launches an `xfce4-terminal` window titled "AI Stack" running `zoth-ai-stack`, associates with the `application/x-zoth-ai-stack` MIME type, and displays the `zoth-ai-stack` desktop icon.
