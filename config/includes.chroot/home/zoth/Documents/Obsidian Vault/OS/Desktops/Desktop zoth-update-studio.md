# Update Zoth Studio

Fetch latest updates and recompile Zoth Studio v2 static distribution

- **Exec:** `/usr/local/bin/zoth-konsole --pause --title "Updating Zoth Studio" -- zoth-update-studio`
- **Categories:** Development;System;Settings;
- **File:** `/usr/share/applications/zoth-update-studio.desktop`
