# Zoth MCP Studio (Beta)

Interactive Model Context Protocol Management & Testing Station.

## Desktop Entry Details

- **Name:** `Zoth MCP Studio (Beta)`
- **Comment:** `Interactive Model Context Protocol Management & Testing Station`
- **Exec:** `/usr/local/bin/zoth-mcp-gui`
- **Icon:** `/usr/share/pixmaps/zoth-mcp.png`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Development;AI;BetaExperimental;`
- **Startup Notify:** `true`
- **File:** `/usr/share/applications/zoth-mcp.desktop`

## Launch Configuration & Behavior

The entry registers Zoth MCP Studio under Development, AI, and BetaExperimental categories. Launching this entry executes `/usr/local/bin/zoth-mcp-gui` as a standalone GUI application without spawning a shell terminal, referencing the desktop pixmap icon at `/usr/share/pixmaps/zoth-mcp.png` and enabling desktop startup notifications.
