# Visual FX Engine

Interactive Cyber Matrix & Datamosh Visualizer.

## Desktop Entry Details

- **Name:** `Visual FX Engine`
- **Comment:** `Interactive Cyber Matrix & Datamosh Visualizer`
- **Exec:** `/usr/local/bin/zoth-live-wallpaper`
- **Icon:** `zoth-live-wallpaper`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Graphics;Utility;`
- **Keywords:** `wallpaper;visual;fx;matrix;datamosh;cyber;`
- **MimeType:** `application/x-zoth-live-wallpaper;`
- **Startup Notify:** `true`
- **File:** `/usr/share/applications/zoth-live-wallpaper.desktop`

## Launch Configuration & Behavior

The entry registers Visual FX Engine under the Graphics and Utility categories. Launching it runs `/usr/local/bin/zoth-live-wallpaper` without a terminal window, binds to the `application/x-zoth-live-wallpaper` MIME type, and displays the `zoth-live-wallpaper` desktop icon.
