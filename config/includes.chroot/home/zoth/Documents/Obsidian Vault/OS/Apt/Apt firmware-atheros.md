# firmware-atheros

Binary firmware for Qualcomm Atheros wireless cards. This package contains the binary firmware for USB wireless network and Bluetooth cards supported by the ar5523, ath3k, ath6kl_sdio, ath6kl_usb, ath10k, ath11k, or wilc6210 drivers.
