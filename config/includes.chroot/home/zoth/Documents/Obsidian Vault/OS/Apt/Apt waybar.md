# waybar

Highly customizable Wayland bar for Sway and Wlroots based compositors. Waybar is a highly customizable wayland bar for Sway and Wlroots based compositors. It features applets displaying information about Sway (Workspaces, Binding mode, Focused window name), Local time, Battery, Network, Pulseaudio, Memory, Cpu load average and custom scripts
