# wofi

application launcher for wlroots based wayland compositors. wofi is an application launcher and menu program for wlroots based wayland compositors such as sway. It brings support for three built-in modes: * drun - launch XDG Desktop files * run - launch executables from $PATH * dmenu - dmenu-compatabile mode to read lines from stdin
