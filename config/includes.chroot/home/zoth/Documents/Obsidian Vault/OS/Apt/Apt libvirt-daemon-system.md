# libvirt-daemon-system

virtualization daemon - typical QEMU-based deployment. libvirt exposes a long-term stable API that can be used to interact with various hypervisors. Its architecture is highly modular, with most features implemented as optional drivers. It can be used from C as well as several other programming languages, and it forms the basis of virtualization solutions tailored for a range of use cases.
