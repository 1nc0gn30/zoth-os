# Zoth Netlify AX & Serverless Edge Console

The **Zoth Netlify AX & Serverless Edge Console** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) under Studio Cockpits & Developer IDEs.

### Core Functionality
Automated edge function deployment, static asset verifier, and production harden pipeline.

### Workstation Metadata
- **ID:** `netlify-ax`
- **Name:** Zoth Netlify AX & Serverless Edge Console
- **Type:** `cockpit` (multi-pane developer IDE and visual operational cockpit for human-agent engineering)
- **Functional Band:** Build
- **Static Entrypoint:** `/studio/netlify-ax.html`
- **In-App Route:** `/workstations/netlify-ax`

### Operational Role
Operates within the Build band to oversee serverless edge infrastructure and Netlify deployment pipelines. It validates static web bundles, automates edge function deployment workflows, and applies pre-deployment production hardening rules.
