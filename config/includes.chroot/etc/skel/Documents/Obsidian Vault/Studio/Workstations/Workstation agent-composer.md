# Multi-Agent DAG Composer & Pipeline Foundry

Visual node-graph builder for orchestrating complex multi-agent execution pipelines.

## Specification & Taxonomy

- **ID:** `agent-composer`
- **Name:** Multi-Agent DAG Composer & Pipeline Foundry
- **Type:** `cockpit` (Multi-pane developer IDE & visual operational cockpit for human-agent engineering)
- **Band:** Build
- **Static Path:** `/studio/agent-composer.html`
- **In-App Route:** `/workstations/agent-composer`

## Operational Profile

Classified under the **Build** functional band as an operational developer cockpit in Zoth Studio v2. Provides a visual node-graph canvas to model, chain, and coordinate directed acyclic graph (DAG) pipelines for autonomous multi-agent execution. Rendered both as a standalone static studio HTML document and as an embedded interactive workstation within the main Studio application.
