# Zoth Tool Bench & Integration Ecosystem

The **Zoth Tool Bench & Integration Ecosystem** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) as an integrated tool in the Tool Arsenal.

### Core Functionality
Integration workbench bridging the 21 sovereign micro-repos and MCP contract endpoints.

### Workstation Metadata
- **ID:** `connectors`
- **Name:** Zoth Tool Bench & Integration Ecosystem
- **Type:** `integrated_tool` (standalone sovereign micro-tool and CLI utility available in the Tool Arsenal)
- **Functional Band:** Observe
- **Static Entrypoint:** `/studio/connectors.html`
- **In-App Route:** `/tools`
- **Tool Repository ID:** `envguard-secrets-vault`
- **Pull / Launch Command:** `npx @nullaitech/zoth tools list`

### Operational Role
Functions within the Observe band to bridge and manage the ecosystem of 21 sovereign micro-repositories alongside Model Context Protocol (MCP) contract endpoints, queryable via the CLI tool list command.
