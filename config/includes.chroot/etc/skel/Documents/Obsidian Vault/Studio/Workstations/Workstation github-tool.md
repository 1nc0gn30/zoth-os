# Zoth GitHub Studio & Autonomous Repo Workstation

Autonomous Git repo management, issue-to-PR pipelines, and commit signer.

## Specification & Taxonomy

- **ID:** `github-tool`
- **Name:** Zoth GitHub Studio & Autonomous Repo Workstation
- **Type:** `cockpit` (Multi-pane developer IDE and visual operational cockpit for human-agent engineering)
- **Band:** Build
- **Static Path:** `/studio/github-tool.html`
- **In-App Route:** `/workstations/github-tool`

## Operational Profile

Registered in the Zoth Studio v2 matrix under the **Build** functional band as a studio cockpit. It provides autonomous Git repository management, automated issue-to-pull-request pipelines, and cryptographic commit signing capabilities. Accessible via the static HTML interface at `/studio/github-tool.html` and within the Studio application at `/workstations/github-tool`.
