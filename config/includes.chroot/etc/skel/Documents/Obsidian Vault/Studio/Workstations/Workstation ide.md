# Sovereign Operator IDE & Code Foundry

The **Sovereign Operator IDE & Code Foundry** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) under Studio Cockpits & Developer IDEs.

### Core Functionality
Air-gapped full code editor, AST syntax inspection, and multi-agent pair programming.

### Workstation Metadata
- **ID:** `ide`
- **Name:** Sovereign Operator IDE & Code Foundry
- **Type:** `cockpit` (multi-pane developer IDE and visual operational cockpit for human-agent engineering)
- **Functional Band:** Build
- **Static Entrypoint:** `/studio/ide.html`
- **In-App Route:** `/workstations/ide`

### Operational Role
Functions within the Build band as an air-gapped developer environment for human-agent engineering. It provides syntax-aware AST inspection, code editing capabilities, and a shared canvas for orchestrating multi-agent pair programming sessions.
