# Shopify Connector // GraphQL Admin & POD Sync Engine

Shopify GraphQL Admin & Antigravity MCP bridge with Etsy-to-Shopify transpiler, profit margin calculator, and draft publisher.

- **ID:** `shopify-connector`

## Operational Profile

Registered in the Zoth Studio v2 matrix under the **Observe** functional band as an integrated sovereign tool. Bridges the Shopify GraphQL Admin API and Antigravity MCP suite, offering an Etsy-to-Shopify listing transpiler, profit margin calculator, and automated draft product publisher. Serves through the static page `/studio/shopify-connector.html`, the in-app tool route `/tools/shopify-connector`, or standalone via `./bin/shopify-connector serve --port 8113`.
