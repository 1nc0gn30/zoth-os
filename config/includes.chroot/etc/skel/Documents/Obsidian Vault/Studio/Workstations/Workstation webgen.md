# Zoth WebGen Foundry

Published Python generator with 6 archetypes and an MCP server. The separate local site foundry keeps the chosen agent working until the site artifact is closed.

## Specification & Taxonomy

- **ID:** `webgen`
- **Name:** Zoth WebGen Foundry
- **Type:** `integrated_tool` (Standalone sovereign micro-tool and CLI utility in the Tool Arsenal)
- **Band:** Build
- **Static Path:** `/studio/webgen.html`
- **In-App Route:** `/webgen`
- **Repository ID:** `zoth-webgen`
- **Pull Command:** `git clone https://github.com/NullAITech/zoth-webgen.git && cd zoth-webgen && python3 webgen_engine.py --help`

## Operational Profile

Registered in the Zoth Studio v2 matrix under the **Build** functional band as an integrated sovereign tool. WebGen provides a Python-based static site generator featuring 6 design archetypes and a Model Context Protocol (MCP) server integration. Its local site foundry workflow keeps the selected agent actively operating until the site artifact is finalized. Accessible via the static HTML interface at `/studio/webgen.html`, in-app at `/webgen`, or directly initialized via its repository pull command.
