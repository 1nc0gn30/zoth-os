# Zoth AX Powerhouse & Contract Studio

The **Zoth AX Powerhouse & Contract Studio** is registered in the Zoth Studio v2 workstations directory (`src/data/workstations.js`) under Studio Cockpits & Developer IDEs.

### Core Functionality
Agent Experience (AX) machine contract compiler, schema validator, and API forge.

### Workstation Metadata
- **ID:** `ax-powerhouse`
- **Name:** Zoth AX Powerhouse & Contract Studio
- **Type:** `cockpit` (multi-pane developer IDE and visual operational cockpit for human-agent engineering)
- **Functional Band:** Build
- **Static Entrypoint:** `/studio/ax-powerhouse.html`
- **In-App Route:** `/workstations/ax-powerhouse`

### Operational Role
Classified under the Build band to provide machine-to-machine interface engineering. It handles compiling Agent Experience (AX) contracts, validating structured schemas, and forging APIs utilized across the agent fleet.
