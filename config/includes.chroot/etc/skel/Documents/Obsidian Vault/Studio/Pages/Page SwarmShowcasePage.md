# SwarmShowcasePage

React product showcase and landing page for **Zoth Swarm Multi-Agent Orchestration**.

- **File:** `zoth-studio-v2/src/pages/SwarmShowcasePage.jsx`
- **Route:** [[Route swarm|/swarm]]

## What It Renders

`SwarmShowcasePage` presents a high-level overview of the local multi-agent pipeline designed for engineers and autonomous development teams.

Key sections rendered:
- **Hero Banner:** Headline emphasizing autonomous multi-model cooperation ("AI Agents That Work Together") executed locally on user hardware.
- **Feature Cards:**
  - *Tri-Agent Pipeline:* Autonomous cooperation between planner, coder, and auditor models.
  - *Self-Coordinating Routing:* Automatic task routing without manual wiring.
  - *Built-In Verification:* Pre-flight validation of all agent outputs.
  - *Fully Local:* Complete local machine execution with zero cloud egress.
- **Target Audience ("Built For"):** Bulleted criteria for AI engineers, autonomous coding teams, and multi-model orchestration researchers.
- **Action CTAs:** Direct navigation button linking to [[Route swarm-docs|/swarm/docs]] and external GitHub repository link.
