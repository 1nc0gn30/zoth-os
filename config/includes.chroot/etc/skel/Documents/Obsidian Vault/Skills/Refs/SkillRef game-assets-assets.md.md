# assets

Game developers ask for WHAT they need, not HOW to make it engine-ready. The how is your job. Apply these defaults whenever the request doesn't say otherwise — an asset that needs manual cleanup is a miss even if the user never mentioned the requirement.

Deliver organized, exactly-named files; if the request leaves counts or naming to you, choose sensible names and document them in a manifest/record.
