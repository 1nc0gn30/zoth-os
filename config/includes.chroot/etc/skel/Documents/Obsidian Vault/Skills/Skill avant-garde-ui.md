# avant-garde-ui

`avant-garde-ui` is a **Grok** design skill providing agents with curated design commodities, distinctive typography systems, and tactile visual primitives to replace generic, cookie-cutter templates with bespoke, high-end interfaces.

- **Origin:** Grok (`~/.grok/skills/avant-garde-ui/SKILL.md`)
- **When to load:** Load when creating or styling frontend web applications, dashboards, or landing pages requiring high-end typography and lightweight pure CSS/JS motion.

### Core Capabilities & Commodities
- **Distinctive Typography Pairings:** Banishes default system fonts in favor of High-Fashion Avant-Garde (`Syne` + `Plus Jakarta Sans`), Industrial Cyber-Grotesque (`Cabinet Grotesk` / `Clash Display` + `Satoshi`), or Mathematical Futurist (`Space Grotesk` + `Inter` / `JetBrains Mono`).
- **Pure CSS/JS Design Primitives:**
  - *Conic Border Beam:* Traveling light outline rendered with CSS `@property --beam-angle` and mask composites.
  - *Ambient Aurora Mesh:* Multi-layered drifting radial gradient background with subtle blur.
  - *Tactile Bento Grids:* 12-column asymmetric responsive grids designed for high information density without clutter.
  - *Rolling Telemetry Counters:* Pure JavaScript `requestAnimationFrame` ease-out number animations.
  - *Shimmering Metallic Gradient Text:* Animated CSS gradient text masking for hero headlines.
- **Design Archetypes:** Enforces three distinct product styles: High-Fashion Avant-Garde (Emerald/Indigo), Sovereign Cyber-Terminal (Solana Green/Cyan), and Industrial Brutalist Engine (Amber/Rose).
- **Verification Checklist:** Verifies typography voice, dynamic motion commodities, hover states, hero impact, and distinct layout structure prior to deployment.
