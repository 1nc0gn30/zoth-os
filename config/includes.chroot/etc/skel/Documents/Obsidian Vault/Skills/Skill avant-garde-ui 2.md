# avant-garde-ui

`avant-garde-ui` is an **AGY** design skill that equips coding agents with curated modern design commodities, distinctive typography systems, and tactile visual primitives to eliminate generic, cookie-cutter UI templates.

- **Origin:** AGY (`~/.gemini/config/skills/avant-garde-ui/SKILL.md`)
- **When to load:** Load when designing or styling frontend web applications, landing pages, or sovereign developer tools that need bespoke, high-converting visual polish.

### Core Capabilities & Commodities
- **Distinctive Typography Systems:** Enforces curated font pairings such as High-Fashion Avant-Garde (`Syne` + `Plus Jakarta Sans`), Industrial Cyber-Grotesque (`Cabinet Grotesk` / `Clash Display` + `Satoshi`), and Mathematical Futurist (`Space Grotesk` + `Inter` / `JetBrains Mono`).
- **Zero-Dependency CSS/JS Primitives:**
  - *Conic Border Beam:* Luminous rotating traveling light beam tracing card outlines via `@property --beam-angle`.
  - *Ambient Aurora Mesh:* Radial blurred gradient background drifting with CSS keyframes.
  - *Tactile Bento Grids:* Responsive 12-column asymmetric grid layouts with fluid mobile breakpoints.
  - *Rolling Telemetry Numbers:* Vanilla `requestAnimationFrame` ease-out number counter for live metrics.
  - *Shimmering Metallic Gradient Text:* Animated linear-gradient text clip for high-impact hero titles.
- **Design Archetypes:** Standardizes three visual archetypes: High-Fashion Avant-Garde (Emerald/Indigo), Sovereign Cyber-Terminal (Solana Green/Cyan), and Industrial Brutalist Engine (Amber/Rose).
- **Pre-Deployment Verification:** Five-point checklist verifying custom typography, active motion primitives, button hover physics, hero impact, and bespoke non-cloned layouts.
