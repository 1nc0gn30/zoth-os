# apparmor-utils

utilities for controlling AppArmor. apparmor-utils provides utilities that operate on AppArmor profiles. Profiles can be created, updated, enforced, set to complain mode, and disabled with tools such as aa-genprof, aa-enforce, aa-complain and aa-disable.
