# firmware-libertas

Binary firmware for Marvell wireless cards. This package contains the binary firmware for wireless network cards with Marvell and NXP 88W8xxx chips supported by the libertas_cs, libertas_sdio, libertas_spi, libertas_tf_usb, mwifiex_pcie, mwifiex_sdio, mwifiex_usb, mwl8k and usb8xxx drivers.
