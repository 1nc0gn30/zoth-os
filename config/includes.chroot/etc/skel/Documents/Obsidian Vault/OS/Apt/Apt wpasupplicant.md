# wpasupplicant

client support for WPA and WPA2 (IEEE 802.11i). wpa-supplicant is a userspace daemon handling connection and authentication in wireless and wired networks, primarily secured with the WPA/WPA2/WPA3 protocols. This software provides key negotiation with the access point (WPA Authenticator), and controls association with IEEE 802.11i networks.
