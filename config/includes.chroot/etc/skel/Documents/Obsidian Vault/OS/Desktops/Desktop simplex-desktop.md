# Zoth SimpleX Sovereign Chat

Zero-Identifier 100% Metadata-Free Private Messenger.

## Desktop Entry Details

- **Name:** `Zoth SimpleX Sovereign Chat`
- **Comment:** `Zero-Identifier 100% Metadata-Free Private Messenger`
- **Exec:** `/usr/local/bin/simplex-desktop`
- **Icon:** `/usr/share/pixmaps/simplex-desktop.png`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Network;Chat;InstantMessaging;`
- **Keywords:** `chat;messaging;im;private;simplex;`
- **Startup Notify:** `true`
- **File:** `/usr/share/applications/simplex-desktop.desktop`

## Launch Configuration & Behavior

The desktop entry registers the SimpleX Chat application within the Network, Chat, and InstantMessaging menus of Zoth OS. It executes the local binary at `/usr/local/bin/simplex-desktop` without spawning an external terminal, displaying a dedicated pixmap icon and providing startup notification upon initialization.
