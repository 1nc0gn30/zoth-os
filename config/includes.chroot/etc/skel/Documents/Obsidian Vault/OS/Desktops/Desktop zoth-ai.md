# ZOTH Master MCP

Master Model Context Protocol Registry.

## Desktop Entry Details

- **Name:** `ZOTH Master MCP`
- **Comment:** `Master Model Context Protocol Registry`
- **Exec:** `xfce4-terminal -T 'ZOTH MCP Hub' -e 'zoth-mcp'`
- **Icon:** `zoth-ai`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Development;ArtificialIntelligence;`
- **Keywords:** `mcp;model-context-protocol;registry;master;ai;`
- **MimeType:** `application/x-zoth-mcp;`
- **Startup Notify:** `true`
- **File:** `/usr/share/applications/zoth-ai.desktop`

## Launch Configuration & Behavior

The desktop entry registers the Master MCP Hub under Development and Artificial Intelligence categories. It invokes `xfce4-terminal` with the title "ZOTH MCP Hub" executing the `zoth-mcp` registry management command, associates with MIME type `application/x-zoth-mcp`, and provides startup notification support.
