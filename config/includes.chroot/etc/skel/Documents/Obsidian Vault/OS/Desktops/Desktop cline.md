# Cline Autonomous Agent

Cline.bot Open-Source Autonomous Coding Agent & CLI.

## Desktop Entry Details

- **Name:** `Cline Autonomous Agent`
- **Comment:** `Cline.bot Open-Source Autonomous Coding Agent & CLI`
- **Exec:** `/usr/local/bin/zoth-konsole --title "Cline AI" -- cline`
- **Icon:** `/usr/share/pixmaps/opencode.png`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Development;AI;`
- **Startup Notify:** `true`
- **Keywords:** `cline;agent;autonomous;coding;ai;bot;`
- **File:** `/usr/share/applications/cline.desktop`

## Launch Configuration & Behavior

Provides a menu launcher for the Cline open-source autonomous coding agent. Instead of spawning a plain terminal, it executes `/usr/local/bin/zoth-konsole` with window title `"Cline AI"` and runs the `cline` CLI tool. It utilizes the shared open-source AI icon at `/usr/share/pixmaps/opencode.png` and integrates into the Development and AI desktop categories.
