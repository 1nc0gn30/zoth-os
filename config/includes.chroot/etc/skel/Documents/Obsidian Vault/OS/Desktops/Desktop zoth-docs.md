The `zoth-docs.desktop` file registers the official ZothOS system guide and architecture manual under the Documentation and Help categories. It directly invokes `/usr/local/bin/zoth-docs` with graphical startup feedback enabled and desktop iconography configured at `/usr/share/pixmaps/zoth-docs.png`.
