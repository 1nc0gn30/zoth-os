# Zoth Terminal (Konsole)

ZothOS Sovereign Shell & HUD Console

## Desktop Entry Details

- **Name:** `Zoth Terminal (Konsole)`
- **Generic Name:** `Command Console`
- **Comment:** `ZothOS Sovereign Shell & HUD Console`
- **Exec:** `konsole`
- **Icon:** `org.kde.konsole`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `System;TerminalEmulator;`
- **Startup Notify:** `true`
- **File:** `/usr/share/applications/zoth-terminal.desktop`

## Launch Configuration & Behavior

The launcher provides quick desktop and menu access to the primary KDE Plasma terminal emulator (`konsole`). It is categorized under System and TerminalEmulator with desktop startup feedback enabled, launching directly as a graphical application window.
