## Launch Configuration & Behavior

The desktop launcher registers the Google Antigravity Agent within the desktop application menu under the Development and AI categories. When launched, it invokes the custom terminal wrapper `/usr/local/bin/zoth-konsole` with the title `"Google Antigravity CLI"`, executing the `antigravity` agent binary within the Zoth environment with desktop startup notifications enabled.
