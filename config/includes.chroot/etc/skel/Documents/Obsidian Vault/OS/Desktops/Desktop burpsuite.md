# Burp Suite Community

Interactive HTTP/HTTPS penetration testing proxy and scanner.

## Desktop Entry Details

- **Name:** `Burp Suite Community`
- **Generic Name:** `Web Security Assessment`
- **Comment:** `Interactive HTTP/HTTPS penetration testing proxy and scanner`
- **Exec:** `/usr/bin/burpsuite`
- **Icon:** `/usr/share/pixmaps/burpsuite.png`
- **Terminal:** `false`
- **Type:** `Application`
- **Categories:** `Network;Security;`
- **Startup Notify:** `true`
- **File:** `/usr/share/applications/burpsuite.desktop`

## Launch Configuration & Behavior

The desktop launcher provides direct system access to the Burp Suite Community Edition application for web security assessments. It registers the executable `/usr/bin/burpsuite` under the Network and Security categories with desktop startup notification enabled and a dedicated icon at `/usr/share/pixmaps/burpsuite.png`.
