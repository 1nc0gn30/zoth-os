# electron

`file`: Bourne-Again shell script.

Image CLI `electron` at `/usr/local/bin/electron` (executable, 2,507 bytes).

**Shebang / kind:** `/usr/bin/env bash`

One Electron runtime (/opt/electron, installed by the 0500-zothos-desktop-apps build hook) for Maya and the Zoth desktop apps. Adds software-rendering flags on VMs / systems without a GPU render node so Electron windows don't come up black (see /usr/lib/zothos/gfx-compat.sh).

Live host also has `/usr/local/bin/electron` after the repo↔OS sync.
