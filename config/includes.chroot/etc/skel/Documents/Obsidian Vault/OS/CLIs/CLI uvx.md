# uvx

Symlink to `/usr/local/bin/uv` (the image wrapper). Chroot entry is a symlink → `/usr/local/bin/uv`.

Image CLI `uvx` at `/usr/local/bin/uvx` (executable, 65,688,664 bytes).

**Shebang / kind:** `binary`

Binary payload in the chroot copy. Header comments are not readable as text.

Live host also has `/usr/local/bin/uvx` after the repo↔OS sync.
