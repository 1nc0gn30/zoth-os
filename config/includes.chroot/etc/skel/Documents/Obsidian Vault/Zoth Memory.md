# Zoth Memory

Federated memory viewer over the Neuro-Memory daemon.

## Run

- Daemon: `127.0.0.1:8094`
- CLI: `zoth-memory` → `~/NullAITech/neuro-memory-daemon/bin/zoth-memory`
- Image wrapper: `zoth-neuro-memory` → `neuro-memory`
- Studio catalog id `neuro-memory-daemon`, liveUrl `https://neuro-memory.nullai.tech`
- Repo: `NullAITech/neuro-memory-daemon`

Desktop `zoth-neuro-memory.desktop` lives in the OS chroot. Copy it onto the live applications dir when missing.
