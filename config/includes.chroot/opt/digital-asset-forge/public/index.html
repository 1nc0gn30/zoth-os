Frequently Asked Questions

      

        

          
Why are 5 different ratio files needed?

          
Store-bought frames use distinct aspect ratios (8x10 is 4:5 while 24x36 is 2:3). Delivering all 5 ratio families lets buyers print any size without awkward cropping.

        

        

          
How does this stay under Etsy's 20 MB ZIP cap?

          
The pack planner bin-packs files using a greedy 18.0 MB per-archive cap into 2 compliant ZIPs (36.1 MB combined), and exports a downloadable ZIP with manifest, guide, and Etsy copy.

        

        

          
Does it run offline via CLI, TUI, and MCP?

          
Yes. Run digital-asset-forge --help, digital-asset-forge-tui --once, or digital-asset-forge mcp for 6 zero-dependency JSON-RPC 2.0 tools.
