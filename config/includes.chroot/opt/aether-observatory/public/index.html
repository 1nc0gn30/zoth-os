FIELD MANUAL — every panel does real work

operating instructions

  1. Sky Map — the constellation viewport

    The centerpiece renders every TCP daemon currently listening on this host as a 3D orbital star. Drag to orbit the camera (yaw/pitch), scroll to zoom (FOV), click any star to lock focus and open the deep socket inspector — real PID, real uptime from /proc/<pid>/stat, real measured latency. Try the three render pipelines from the mode rack: 01 VECTOR (perspective starfield + depth-sorted edges), 02 BRAILLE (Unicode U+2800 2×4 sub-pixel matrix — silent, generative monochrome), 03 DITHER (Bayer 8×8 one-bit halftone with phosphor scanlines).

  2. Meters — split-flap flight odometers

    Mechanical flap drums read the machine aloud: uptime since boot, live listening socket count, and CPU package temperature from sensors(1) / /sys/class/thermal/*. Every value flips only when the real reading changes.

  3. Sonorium — the acoustic telemetry deck

    Press PLAY DRONE (opt-in; browsers require a user gesture for audio). Four rotary knobs conduct real system physics into synthesis: CPU LOAD → PITCH, MEM PRESSURE → HARMONICS, THERMAL → BRIGHTNESS (filter cutoff), SOCKETS → DRIFT (LFO). Drag a knob vertically; watch the 60fps FFT waterfall paint what the drone hears. Drag=relative, wheel=fine, keys ↑↓←→ are accessible.

  4. Timeline — the flight recorder

    A SQLite ring-buffer snaps a telemetry frame every ten seconds (24 h rolling). Scrub the strip to scrub memory; press DIFF and tap two epochs to compare them — terminated ports, spawned daemons, thermal spikes and load swings surface as chips. EXPORT emits a clean Markdown or JSON incident report of exactly that window.

LIVE FEED — nothing on this page is mocked. CPU reads /proc/stat deltas, thermals read /sys/class/thermal + sensors(1), sockets read ss -tlnp matched against the Zoth Studio registry (zoth-studio-v2/toolsData.js), and the git pulse walks ~/NullAITech repos for 14-day commit activity.

Telemetry cadence: 10s persists to data/aether-flight.db · stream over SSE · CLI: aether-observatory status|constellation|snapshot|serve.
