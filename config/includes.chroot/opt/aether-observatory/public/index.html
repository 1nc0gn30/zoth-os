Operating Instructions

  1. Sky Map — 3D Daemon & Port Constellation

    Every listening TCP socket from ss -tlnp is mapped to concentric 3D orbits and joined with the Zoth Studio registry. Drag to orbit, wheel/pinch to zoom, click any star to open the Deep Socket Inspector with PID, protocol, uptime from /proc/<pid>/stat, latency, and secret-redacted command line. Switch between 01 VECTOR, 02 BRAILLE (U+2800 2×4 sub-pixel matrix, interactive), and 03 DITHER (Bayer 8×8 halftone).

  2. Meters — Split-Flap Flight Odometers

    Live uptime hours, listening socket count, and CPU package temperature (prioritizing Package id 0 / x86_pkg_temp over NVMe sensors).

  3. Sonorium — WebAudio Acoustic Telemetry Deck

    Press PLAY DRONE to initialize WebAudio on user gesture. Live CPU load, RAM pressure, package thermal, and open sockets modulate pitch, harmonic richness, lowpass cutoff, and LFO drift through a DynamicsCompressorNode master limiter into a 60fps FFT waterfall. Drag any rotary dial vertically (or use wheel / arrow keys) to override.

  4. Time Machine & Sovereign AI Triage

    A persistent SQLite ring-buffer records a compact frame every 10 seconds (8,640 rows = 24h). Scrub chronologically in SCRUB mode, compare any two timestamps in DIFF T1/T2 mode, download Markdown or JSON reports, or run optional local AI triage via AGY Bridge (:18000), Ollama (:11434), or built-in deterministic rules.

CLI & MCP: aether-observatory status [--json] | constellation [--json] | snapshot [--json] | mcp | serve --port 8160. Zero external fonts, zero trackers, loopback-only CORS.
