Frequently Answered Questions

How does Agent Mock Twin eliminate API token costs for autonomous agents?

Agent Mock Twin ingests real LLM provider traffic (OpenAI, Anthropic, Ollama, REST) via standard HAR 1.2 or OpenAPI 3.0 specs into SQLite WAL storage and replays deterministic responses locally on 127.0.0.1:8097 with zero outbound billing.

Does Agent Mock Twin require external pip dependencies?

No. The runtime is built 100% on the Python 3.10+ standard library (http.server, sqlite3, dataclasses, urllib.parse) with zero external CDNs.

How do CI/CD pipelines and MCP agents connect?

Wrap CI commands with agent-mock-twin run -- pytest tests/ to auto-redirect OPENAI_BASE_URL and ANTHROPIC_BASE_URL, or start the 4-tool JSON-RPC 2.0 stdio MCP server via agent-mock-twin mcp.
