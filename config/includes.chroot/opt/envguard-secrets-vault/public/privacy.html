Privacy Policy

Effective 2026-11-26 · Zero-Exposure Local Processing Guarantee

1. Zero Telemetry & Zero External Egress

EnvGuard Secrets Vault does not collect analytics, cookies, tracking pixels, crash dumps, or environment secrets. All static pages load zero third-party fonts or external scripts.

2. Local-Only Cryptographic Execution

  • When used statically in a browser, all scanning, masking, PBKDF2 + AES-256-CTR-HMAC-SHA256 encryption, Shamir GF(256) splitting, and rotation checks run purely inside your browser sandbox.
  • When paired with the local Python daemon on 127.0.0.1:8088, requests stay strictly on local loopback with Host/Origin validation and zero filesystem path exposure over HTTP.
  • Only your theme preference (envguard-theme) is stored in browser localStorage.
